# MIDI作曲エディター（自分用・ブラウザ版）

メロディー、コード伴奏、ドラムを打ち込めるMIDIエディターです。PCの Chromium 系ブラウザ（Chrome・Edge）とマウスで使います。
要件は `02_REQUIREMENTS.md`、設計は `04_DESIGN.md`、実装状況は `05_IMPLEMENTATION_REPORT.md` にあります。

## 起動のしかた

前提: Node.js（v22 で確認）が入っていること。

- いちばん簡単な方法: `start.bat` をダブルクリックします。初回は必要な部品を取得し、ブラウザで `http://localhost:4173/` を開きます。
- コマンドで起動する場合:

```bash
npm install
```

```bash
npm start
```

開発中（ファイルを直すとすぐ反映）は `npm run dev` を使い、`http://localhost:5173/` を開きます。

`index.html` を直接ダブルクリックして開く方法（`file://`）では、音源とファイル保存が動きません。必ず上の方法で起動してください。

## 最初の操作

1. 画面のどこかをクリックすると、音声が有効になります（ブラウザの決まりで、最初の操作が必要です）。右上に「音声: 準備完了」と出れば音が鳴ります。
2. ピアノロールの空いているところをクリックすると音符を置けます。音の長さと吸着（スナップ）は上の入力バーで選びます。
3. Space で再生・停止します。
4. Ctrl+S で保存します（`曲名.mcproj.json`）。MIDIファイルは「ファイル ▾ → MIDI書き出し」で作ります。
5. 保存したプロジェクト（.mcproj.json）や MIDI ファイル（.mid）は、画面にドラッグ＆ドロップしても開けます。

操作の一覧は画面下の「操作の一覧」から開けます。

## 開発者向け

```bash
npm test
```

```bash
npm run typecheck
```

| 場所 | 内容 |
|---|---|
| `src/model/` | 曲データの型、時間・吸着の規則、編集操作（純粋関数）、取り消し、重なりの変換規則 |
| `src/theory/` | スケール、コード、進行、弾き方（挿入する音符の生成） |
| `src/midi/` | 標準MIDIファイルの書き出し（独自実装）と読み込み（@tonejs/midi） |
| `src/io/` | プロジェクトファイルの形式と検証 |
| `src/audio/` | 音源（SpessaSynth）と再生スケジューラー |
| `src/ui/` | 画面（Preact）。ピアノロールと全体表示はキャンバスで描画 |
| `tests/` | 自動テスト（Vitest） |
| `public/soundfonts/` | 音色データ GeneralUser GS（利用条件は同じフォルダの LICENSE） |
